# Gen-Ardent Immigration Web Application

A complete client-side web application for the IT1308 Web Application Development assignment. The site presents Gen-Ardent Immigration Inc Sri Lanka as a professional immigration consultancy for Canada and global visa pathways.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- localStorage for theme preference and simulated client-side submissions
- Google Fonts
- Font Awesome icons

## How to Run

Open `src/index.html` in a web browser. No backend, database, PHP, Node.js, Firebase or server setup is required.

## Main Features

- Responsive desktop, tablet and mobile layout
- Home, Canada, Other Countries, Legal Services, Consultation, About, Career and Contact pages
- Search with dynamic service results
- Rule-based floating chatbot
- Dark mode and light mode with saved preference
- FAQ accordions
- Inquiry, booking, contact, career, review and newsletter forms
- Client-side validation and success messages
- CV upload simulation using `input type="file"`
- Promotional advertisement cards
- Testimonials and migration success stories
- Service recommendation selectors
- Placeholder map cards and trusted official links
- Scroll-to-top button, loading indicator and smooth UI transitions
