Gen-Ardent Immigration Web Application Documentation

1. Introduction

The Gen-Ardent Immigration Web Application is a complete client-side website created for Gen-Ardent Immigration Inc Sri Lanka. The purpose of the project is to present immigration consultancy services in a professional, trustworthy and responsive format while focusing on Canada as the priority destination. The website also promotes visa services for Australia, New Zealand, the United Kingdom, the United States and Europe.

The web application helps clients discover visa pathways, submit inquiries, book consultations, upload CV files for evaluation, subscribe to newsletters, read testimonials, submit reviews and contact office locations. The project is designed for a university web application development assessment and uses only HTML, CSS and JavaScript.

2. System Overview

The system is a static client-side web application. It does not require a backend server or database. All interaction is handled in the browser using JavaScript and localStorage.

Main pages:
- Home page: promotions, service categories, testimonials, newsletter, chatbot and global navigation.
- Canada Immigration page: Canada services, FAQ, inquiry form, CV upload and recommendation widget.
- Other Countries page: country services, scholarship promotion, FAQ, inquiry form and recommendation widget.
- Legal Services page: legal service cards, trust badges, FAQ and legal inquiry form.
- Consultation Booking page: booking form, CV upload, localStorage booking save and office availability cards.
- Success Stories / Reviews page: success cards, testimonials, review form and saved reviews.
- About Us page: company profile, mission, vision, values, offices, team and credentials.
- Career page: job openings and career application form with CV upload.
- Contact page: contact details, office cards, map placeholders, contact form, social media and trusted external resources.

Major features:
- Responsive navigation
- Search dropdown
- Dark/light mode with localStorage
- Floating chatbot
- FAQ accordion
- Form validation
- CV upload filename display
- Newsletter storage
- Booking storage
- Review storage and dynamic rendering
- Scroll-to-top button
- Loading indicator
- Service recommendation widgets
- Active navigation link
- Responsive design and animations

7. Storyboard

Service Discovery -> Service Selection -> Inquiry/Booking -> Form Submission -> Confirmation

Service Discovery:
The user opens the home page and sees visa promotions, Canada focus, service cards and search.

Service Selection:
The user searches for a service or clicks a service card such as Canada Immigration or Legal Services.

Inquiry/Booking:
The user reviews details, opens FAQ sections and fills an inquiry or booking form.

Form Submission:
JavaScript validates the required fields and email format, prevents page reload and saves demo data where required.

Confirmation:
The system displays a success message confirming that the inquiry, booking, review, newsletter subscription or application was submitted.

Color palette:

- Secondary: #09213F

- Canada accent: #C81E1E

- Text dark mode: #F8FAFC
- Muted text: #64748B

Typography:
The website uses Poppins from Google Fonts. H1 text is approximately 48px on desktop and 34px on mobile. H2 text is approximately 36px on desktop and 28px on mobile. H3 text is 24px. Body text is 16px.

Buttons:
Primary buttons use blue background and white text. Secondary buttons use transparent styling with a border. Accent buttons use gold background. Hover states include small movement and color changes.

Icons:
The project uses Font Awesome icons through CDN for navigation, cards, buttons, badges, forms and chatbot.

Layout and spacing:
The maximum content width is 1200px. Desktop sections use 80px vertical padding and mobile sections use 50px. Cards use soft shadows, consistent gaps and rounded corners. Forms use 14px padding on inputs.

Light mode and dark mode:
CSS custom properties define the design tokens. JavaScript toggles a dark-mode class on the body and saves the user preference in localStorage.

  --accent: #D4AF37;
  --background: #F7FAFC;
  --surface: #FFFFFF;

These variables keep the design consistent and make theme changes easier.

JavaScript dark mode:

document.body.classList.toggle("dark-mode", isDark);
localStorage.setItem("genArdentTheme", isDark ? "dark" : "light");

This code toggles the dark-mode class and saves the selected mode in localStorage.

JavaScript search:

});

This code searches service data by title, description and keywords.

const found = chatbotReplies.find((item) =>

This code matches a user message with predefined chatbot keywords.

JavaScript form validation:

form.querySelectorAll("[required]").forEach((field) => {

  }

This code checks required fields and displays field-level error messages.

11. Chatbot Explanation

The chatbot is a floating client-side widget on all pages. When the user opens it and types a question, JavaScript checks the message against predefined keyword groups. The chatbot handles:
- Canada visa
- student visa
- scholarship
- legal appeal
- book consultation
- contact
- nurse migration
- family sponsorship

If a keyword is matched, the bot replies with a useful suggestion and points the user to the relevant page. If there is no match, it gives a general help message listing supported topics.

12. Search Bar Explanation

The search bar uses a JavaScript array called searchData. Each item contains a title, page URL, description and keywords. When the user types, JavaScript filters the array and displays matching results in a dropdown. Clicking a result navigates to the relevant page.

Supported keywords include Canada, student visa, work visa, scholarship, legal, appeal, refugee, booking, consultation, contact, career, family sponsorship, nurse migration, PR and visit visa.

13. Logo Design Explanation

The logo uses professional immigration branding with a global, trust-focused and Canada-priority theme. The circular globe icon communicates international movement, while the Gen-Ardent name and Sri Lanka label communicate the company identity and local presence.

14. Promotional Advertisement Design Explanation

The website uses promotional cards for Canada PR Pathway, Student Visa with Scholarship up to 70%, Nurse Migration Program, Quick Visit Visa Support and Family Sponsorship Program. These cards are designed as campaign-style advertisements that guide users toward high-interest immigration services.

16. Testing and Results

The website was checked for desktop, tablet and mobile screen sizes using responsive CSS grid, flexbox and media queries. Navigation links point to the correct pages. The shared JavaScript supports form validation, search dropdown, chatbot, FAQ accordion, localStorage features, theme toggle, scroll-to-top and recommendation widgets.

Expected results:
- Pages load without backend requirements.
- Navbar links work across all pages.
- Forms prevent page reload and show success or error messages.
- CV upload displays selected file name.
- Review submissions appear dynamically and persist after reload.
- Newsletter emails are saved to localStorage.
- Dark/light preference persists after reload.
- Search results navigate to relevant pages.

17. Challenges and Solutions

Challenge: Making UI responsive
Solution: CSS grid, flexbox and media queries were used to adapt cards, forms, navigation and page sections for desktop, tablet and mobile views.

Challenge: No backend
Solution: localStorage and client-side validation were used for demo data such as bookings, reviews, inquiries and newsletter subscriptions.

Challenge: Improving user interaction
Solution: The project includes chatbot replies, FAQ accordion behavior, search dropdowns, animations, hover effects, recommendation widgets and scroll-to-top behavior.
