# Style Guide

## Brand Feel

Professional, trustworthy, clean, global and premium without feeling crowded.

## Colors

- Primary: `#0B3D91`
- Secondary: `#D71920`
- Accent: `#F4B400`
- Light background: `#F8FAFC`
- Light text: `#1E293B`
- Dark background: `#0F172A`
- Dark text: `#E5E7EB`

## Typography

- Headings: Poppins, Arial, sans-serif
- Body: Inter, Arial, sans-serif

## UI Components

- Navigation: sticky header with search, theme toggle and mobile menu.
- Cards: 8px radius, light shadow, hover lift.
- Buttons: icon plus label for clear commands.
- Forms: labels, required validation, error text and confirmation messages.
- Chatbot: floating launcher and predefined response window.

## Accessibility

Use semantic HTML, alt text, labels, aria-live feedback messages and keyboard-friendly buttons.
